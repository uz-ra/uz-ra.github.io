# Penelope Caption Studio

写真展用の作品情報をCSVから読み込み、A4横・1ページ6作品のキャプションを編集、印刷できるツールです。

画面プレビューはA4実寸の印刷レイアウト全体を縮小表示するため、PDF／印刷時と同じ文字サイズ・余白・配置になります。

## Web UI

<https://uz-ra.github.io/penelope/>

### 使い方

1. UTF-8のCSVを「CSVを選ぶ」から選択するか、画面へドロップします。
2. 表示された「CSV列を割り当てる」画面で、作品タイトル・作者名・大学名などに使う列を確認します。既知の列名は自動選択され、表記が異なる列はプルダウンから手動で指定できます。
3. 読み込み後に列の対応を変える場合は、左上の「列」ボタンから「CSV列を再割り当て」を開きます。
4. 左上の「＋」または初期画面の「手動で作品を追加」から、CSVを使わず空の作品キャプションを追加できます。
5. 左側の作品一覧から作品を選び、右側のフォームで内容を確認・編集します。
6. 「文字設定」を開くと、タイトル・所属／作者・キャプション・撮影情報の文字サイズを変更できます。「変更対象」で、選択中の作品だけの個別変更と、全作品の一括変更を切り替えられます。
7. SNSリンクから作るQRコードでは、「QRリンクのクエリを削除」が初期状態でオンになっており、URLの `?` 以降の追跡情報を除きます。必要な場合はオフにできます。
8. 絞り値の表記を揃える場合は「絞り値のFを統一」をオンにし、`ƒ`（初期値）、`F`、`f`など任意の先頭文字と斜体の有無を指定します。オフにするとCSVの元表記をそのまま使用します。
9. 矢印ボタンで作品の順番を変更できます。
10. 「CSVを書き出す」で保存ファイル名を指定して編集結果を保存し、「PDF / 印刷」で印刷またはPDF保存します。作品ごとの文字サイズとCSV列の割り当ても書き出され、再読み込み時に復元されます。

CSVの内容はサーバーへ送信されず、ブラウザ内だけで処理されます。読み込み元にあった未使用の列も、CSV書き出し時にそのまま保持されます。書き出しCSVには列割り当て復元用の `Penelope列割り当て` 列も追加されます。

列名を自動照合するときは半角・全角を含む空白を無視します。たとえば `作品タイトル / Title` と `作品タイトル/Title` は同じ列として認識します。自動認識されない独自の列名も、読み込み時に手動で割り当てられます。CSVを書き出す際の列名は、読み込み元の表記を保持します。

## 対応するCSV列名

### 必須

| 列名 | 内容 |
| --- | --- |
| `作品タイトル / Title` | 作品タイトル。列自体は必須ですが、値が空の行も読み込み、「タイトル未入力」として要確認に数えます。 |

### 任意

| 列名 | 内容 |
| --- | --- |
| `表記する名前 / Written name` | キャプションに表示する作者名。 |
| `表示する名前 / Written name` | 上記の作者名列として同様に認識します。 |
| `表示する名前` | 上記の作者名列として同様に認識します。 |
| `本名 / Full name` | 表示する作者名が空の場合の代替名。 |
| `所属大学 / University` | 所属大学。` / ` 区切りの後半は表示時に省略されます。 |
| `学年/Grade` | 学年。` / ` 区切りの後半は表示時に省略されます。 |
| `キャプション / Caption` | 作品説明。`キャプション無し`、`キャプションなし`、`なし`、`無し`、`-` は空欄として扱います。 |
| `SNSアカウントのリンク / Link of social media account *optional` | QRコードにするURL。 |
| `撮影場所 / Location` | 撮影場所。 |
| `使用機材 / Camera` | カメラ名。 |
| `使用レンズ / Lens` | レンズ名。 |
| `シャッタースピード / Shutter Speed` | シャッタースピード。必要に応じて末尾に `s` を付けて表示します。 |
| `絞り値 / Aperture` | 絞り値。 |
| `ISO感度（使用フィルム） / ISO(Film name)` | ISO感度またはフィルム名。 |

### 書き出し時に追加される文字設定列

| 列名 | 内容 |
| --- | --- |
| `文字サイズ：作品タイトル（%）` | 作品タイトルの文字サイズ。 |
| `文字サイズ：所属・作者（%）` | 所属・作者の文字サイズ。 |
| `文字サイズ：キャプション（%）` | キャプションの文字サイズ。 |
| `文字サイズ：撮影情報（%）` | 撮影場所・機材・レンズ・撮影設定の文字サイズ。 |
| `文字サイズ基準バージョン` | 文字サイズの基準を識別するため、書き出し時に自動追加されます。通常は編集不要です。 |
| `Penelope列割り当て` | CSV列の割り当てを次回読み込み時に復元する情報です。通常は編集不要です。 |

初期値はすべて `100%` です。これは従来設定の作品タイトル `140%`、所属・作者 `140%`、キャプション `130%`、撮影情報 `150%` と同じ実寸です。各値は作品ごとに保存され、書き出したCSVを再度読み込むと自動的に復元されます。旧基準で保存したCSVは、同じ見た目を保つ新基準の値へ読み込み時に自動換算されます。

作者名の列が複数ある場合は、表の上にある列名から優先して使用します。編集済みCSVを書き出す際は、読み込み時に使われていた作者名の列へ値を戻します。

## ローカル版（Python）

Web UIとは別に、画像とPDFを一括生成する従来のPythonスクリプトも利用できます。

### 必須環境

- macOS
- Python 3.10以上
- `HannariMincho-Regular.otf`（`~/Library/Fonts/`）
- `Avenir Next.ttc`（macOS標準）
- `ヒラギノ角ゴシック W1.ttc`（macOS標準）

### セットアップ

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pillow qrcode pilmoji
```

### 実行

```bash
python penelope2.py --csv input.csv --out build/photo_exhibition_pages
```

- `--csv`: 読み込むCSV（既定値: `input.csv`）
- `--out`: PNGの出力先（既定値: `build/photo_exhibition_pages`）

出力されるファイル:

- `build/exhibition_captions.pdf`: 全ページをまとめた印刷用PDF
- `build/photo_exhibition_pages/page_*.png`: 各ページのPNG画像
